# Claude

A small sample Python project used to practice the GitHub workflow (branches, commits, and pull requests).

## Contents

- `hello.py` — a couple of simple, well-tested example functions
- `tests/test_hello.py` — unit tests for `hello.py`

## Usage

```bash
python hello.py
```

## Running tests

```bash
python -m unittest discover tests
```
